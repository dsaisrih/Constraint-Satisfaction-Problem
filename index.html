🧠 What is CSP?

A Constraint Satisfaction Problem (CSP) is a problem where we must assign values to variables while satisfying constraints.

Main Components

  • Variables – Items to assign values
  • Domain – Possible values
  • Constraints – Rules restricting values

Examples include map coloring, cryptarithmetic puzzles, and scheduling problems.
